# Opening the app

**Feature:** Opening the app
**Severity:** Critical
**Status:** ready
**Created:** 2026-11-20

## Preconditions

The project's packages are installed (`npm install` has been run in the project folder).

## Steps

1. Start the app with `npm run dev`
2. Open a web browser
3. Go to http://localhost:5173

## Expected result

The page loads and shows the heading "Bootcamp App", the line "Your app is up and running.", and a green box that says "Server says: Hello from the server!"
